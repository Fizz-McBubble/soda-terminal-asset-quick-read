# Independent Asset Quick Read installer

The default output is a real Windows x64 .NET 8 self-contained compressed single-file installer: `Soda-Asset-Quick-Read-Setup-1.0.0.exe`. The standard SDK single-file publisher embeds the reviewed runtime payload and its SHA-256 catalog. It needs neither a separately installed .NET runtime nor NSIS to run. NSIS 3.13 remains an optional packaging wrapper with its unchanged pinned toolchain and complete mixed-license notice; it is not part of the default shipped installer.

```powershell
./Build-Bridge.ps1 -DotNetPath <dotnet.exe> -OutputDirectory <new-build-directory> -RunTests
./Build-AssetQuickReadInstaller.ps1 -DotNetPath <dotnet.exe> -BridgeOutputDirectory <new-build-directory> -OutputDirectory <new-installer-directory> -RunTests
```

Build uses the .NET 8 SDK, win-x64 runtime/reference packages at 8.0.29; standard NuGet sources are used when dependencies are not already cached. All output directories must be new. Optional `-NsisPath <makensis.exe>` checks the exact compiler hash in `installer/nsis-toolchain.json`. No build or self-test writes HKCU, requests UAC, captures traffic, loads a driver or reads a player's game files. Self-tests substitute local fixture protocol streams; they never download protocol data.

Only clicking **安装** authorizes the installer to create `%LOCALAPPDATA%/SodaTerminal/AssetQuickRead/versions/1.0.0`, register the current-user protocol and add `Soda Terminal 资产快读` to the Start menu. The installer displays this boundary before installation. The complete .NET/runtime/WinDivert file payload is embedded. The three protocol JSON files are deliberately absent from the embedded payload because their distribution permission is separate from the upstream MIT code license. Installation downloads exactly these public files from the fixed upstream commit, with no cookies, credentials or redirects:

- `https://raw.githubusercontent.com/pingwinekZ/zzz_packet_capture_0delay/4853f07c8fb5322c12b9b580d6364b577c2ac96a/assets/manifest.json`
- `https://raw.githubusercontent.com/pingwinekZ/zzz_packet_capture_0delay/4853f07c8fb5322c12b9b580d6364b577c2ac96a/assets/datamine.json`
- `https://raw.githubusercontent.com/pingwinekZ/zzz_packet_capture_0delay/4853f07c8fb5322c12b9b580d6364b577c2ac96a/assets/nap.json`

The installer shows byte-based copy/download progress and supports cancellation, errors and retry. Every downloaded file must match the fixed protocol size and SHA-256. No completed version or protocol registration is created on a failed/cancelled download. Only this operation's newly created staging/version files are rolled back; jobs, other versions and unknown same-version content are preserved. A verified identical version can be reopened without replacing its files. Existing foreign protocol or Start-menu registrations are rejected rather than overwritten. The final directory is promoted atomically before registration; registration failure rolls back its new registration and new version.

The registered command is `"<installed bridge exe>" --protocol "%1"`. Only the exact `soda-asset-quick-read://launch` and its single trailing-slash form are accepted. Queries, fragments, arguments, targets, encoded paths and arbitrary URLs are rejected. Protocol and Start-menu launch start an ordinary Kestrel loopback server at `127.0.0.1:50609`; they do not request UAC or change HTTP.sys URLACL/firewall settings. Duplicate opening verifies a current-user named pipe's OS process owner, the executable and assembly hashes, and health identity before exiting successfully. Unknown/different-build services or occupied ports fail without stopping another process. The named pipe contains only a public version marker, never tokens or account data.

`GET /health` reports `service=soda-asset-quick-read`, `version=1.0.0`, `protocolVersion=1`. Actual capture retains the bridge's original exact Origin, Host, RAM-token, explicit `riskAcknowledged`, game-closed preflight, fixed runtime/driver/protocol hash, ready-based 180-second timer and cancellation/late-result protection. Only authenticated `POST /jobs` can request UAC. Installing or opening is not capture acceptance.

The payload includes upstream MIT, complete WinDivert LGPLv3/GPLv3/GPLv2, .NET runtime license and third-party notices. The matching official WinDivert 2.2.2 corresponding-source ZIP is supplied alongside the release installer; it is not installed into the user's runtime directory. Source and application-code rebuilding are documented by the standalone public repository. First installation into the real user directory, protocol registration, real UAC/driver/game capture and user acceptance are separate checks and are not performed by build/self-tests.

`installer/Rust-DEPENDENCY-NOTICES.txt` contains the complete license/copyright/NOTICE documents from all 70 locked registry dependencies and five upstream path crates, including combined-license dependencies such as ring/BoringSSL and Unicode. `Rust-STDLIB-COPYRIGHT.html` preserves the pinned Rust 1.97.1 standard-library copyright and license notice in full. Both files are included under the installed `licenses/` directory. `Build-RustDependencyNotices.ps1 -OutputDirectory <new-directory> -CargoPath <cargo.exe> -RustcPath <rustc.exe>` regenerates these solely from locked offline Cargo metadata and checksum-verified cached `.crate` archives; it never prints machine-specific metadata paths. It includes Apache NOTICE files whenever present, fails if a complete license document/archive is missing, and records the Cargo.lock hash. Installation packaging rejects stale/missing notices. The WindowsDesktop 8.0.29 runtime nupkg contains a complete `LICENSE` and no separate third-party-notices document; packaging also checks all runtime nupkg entries for any additional notices instead of relying only on extracted cache filenames.
